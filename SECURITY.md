## Reporting a Vulnerability

We take the security of the VoltarisOS platform seriously. If you believe you have found a security vulnerability, please report it to us as soon as possible.

### How to report a vulnerability

Please do not report security vulnerabilities via public GitHub issues. Instead, please send an email to **[insira_seu_email_aqui@exemplo.com]**.

When reporting, please provide:
*   A clear description of the vulnerability.
*   Steps to reproduce the issue.
*   Any relevant logs or output that demonstrate the problem.

### What to expect

*   We will acknowledge receipt of your report within 48 hours.
*   We will investigate the issue and communicate a timeline for a fix.
*   We kindly ask you to keep the report confidential until we have had sufficient time to analyze and address the issue.

We appreciate your commitment to making this platform more secure.
