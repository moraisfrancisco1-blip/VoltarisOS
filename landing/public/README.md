### Como capturar screenshots:

1. Abra o VoltarisOS no navegador
2. Navegue até a página desejado
3. Use Ctrl+Shift+P (ou Cmd+Shift+P no Mac)
4. Digite "screenshot" e selecione "Capture full size screenshot"
5. Salve na pasta `landing/public/` com os nomes acima

### Ou use imagens placeholder:

Enquanto não adiciona as imagens reais, a landing page usa mockups SVG animados.
